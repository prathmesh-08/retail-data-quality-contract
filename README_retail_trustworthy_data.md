# Retail Orders — Trustworthy Data Deliverable

Decision owner: Commerce / Operations Manager.

This package translates the ambiguous requirement “trustworthy retail data” into:
1. A KPI dictionary with formula, grain, filters, owner and cadence.
2. An executable Python/Jupyter profiling notebook.
3. A data-quality contract with measurable thresholds and escalation actions.

Files:
- `retail_trustworthy_data_kpi_dictionary.xlsx`
- `retail_orders_data_quality_profile.ipynb`
- `retail_data_quality_contract.md`

The raw sample contains intentional defects, so the notebook should report FAIL. That is expected and demonstrates that the agreement is testable.
